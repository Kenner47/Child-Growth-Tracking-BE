# 👶 Child Growth Tracking System

This is a group project developed during our semester at FPT University (HCMC).  
The system helps parents track their child’s growth from infancy to adulthood.

> 🔒 The original repository is private.  
> 📥 This version is re-uploaded to demonstrate my personal contributions to the back-end.

---

## 🧑‍💻 My Role: Back-End Developer (Partial Contribution)

I was responsible for developing and implementing the following features:

- **Reset Password / Forgot Password** functionality for user authentication
- **CRUD operations for Product Management**
- A supporting feature for **deleting a child's profile** (soft delete)

All functionalities were implemented using **ASP.NET Core** and **Entity Framework Core**, with **SQL Server** as the database.

---

## 🛠️ Technologies Used

**Frontend:** (developed by team) ReactJS, Vite, Tailwind CSS, Bootstrap  
**Backend:** C# (.NET Core), SQL Server, Swagger  
**Others:** PayOS (Payment Integration), GitHub, Visual Studio Code, Rider
